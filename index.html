О проекте

Цель системы

Автоматизация поиска нестандартных городских объектов (тихие дворы, панорамные площадки, места для встреч) с фильтрацией по уровню приватности и удобными маршрутами.

Технический стек

HTML5, CSS3, JavaScript, Bootstrap 5, интеграция с REST API сторонних навигаторов и карта локаций.

Функциональные модули

Модуль 01

Сервис и Интерактивная карта

В разработке

Ключевой клиентский блок приложения для поиска, визуализации и работы с локациями.

Запланированный функционал:
  • Интерактивная карта с метками объектов
  • Фильтрация по категориям и уровню уединённости
  • Построение авторских прогулочных маршрутов
Модуль 02

Авторизация и Права доступа

В разработке

Подсистема управления пользователями, сессиями и разграничением прав доступа (RBAC).

Запланированный функционал:
  • Регистрация, аутентификация и личный кабинет
  • Роли: Гость, Пользователь, Модератор, Админ
  • Нейросетевая фильтрация текста и отзывов
